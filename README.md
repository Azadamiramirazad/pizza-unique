# پیتزا یونیک - سایت پیتزا فروشی

یک وب‌سایت ساده و مدرن برای پیتزافروشی با PHP و SQLite.

## ویژگی‌ها

- طراحی مدرن و ریسپانسیو (RTL / فارسی)
- صفحه اصلی با منوی پیتزا
- **ثبت‌نام با شماره موبایل + کد تأیید (OTP)**
- صفحه ورود
- پنل کاربری ساده
- دیتابیس SQLite (بدون نیاز به نصب MySQL)

## نحوه اجرا

1. فایل‌ها را روی یک سرور PHP (مثل XAMPP، Laragon، یا سرور واقعی) قرار دهید.
2. مطمئن شوید PHP نسخه ۷.۴ یا بالاتر دارید و extensionهای `pdo_sqlite` فعال است.
3. به آدرس سایت بروید (مثلاً `http://localhost/pizza-unique`).

### اجرای سریع با PHP Built-in Server:

```bash
cd pizza-unique
php -S localhost:8000
```

سپس مرورگر را روی `http://localhost:8000` باز کنید.

## جریان ثبت‌نام

1. نام + شماره موبایل (فرمت ۰۹xxxxxxxxx)
2. دریافت کد ۶ رقمی (در حالت دمو کد روی صفحه نمایش داده می‌شود)
3. تأیید کد
4. تعیین رمز عبور
5. ورود خودکار به پنل

## حالت دمو OTP

چون سرویس SMS واقعی متصل نیست، کد تأیید روی صفحه نمایش داده می‌شود تا بتوانید تست کنید.

برای اتصال به SMS واقعی (مثل کاوه‌نگار، ملی‌پیامک و ...) می‌توانید در بخش `send_otp` تابع ارسال پیامک اضافه کنید.

## ساختار فایل‌ها

```
pizza-unique/
├── index.php        # صفحه اصلی
├── register.php     # ثبت‌نام + OTP
├── login.php        # ورود
├── dashboard.php    # پنل کاربری
├── logout.php       # خروج
├── config.php       # تنظیمات session و توابع کمکی
├── db.php           # اتصال SQLite
├── style.css        # استایل مدرن
├── pizza.db         # دیتابیس (خودکار ساخته می‌شود)
└── README.md
```
